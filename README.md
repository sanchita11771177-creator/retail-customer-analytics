# Retail Customer Analytics

A portfolio project for entry-level Data Analyst / Data Analytics applications.

## Tools
Python, Pandas, Matplotlib, SQL

## What I analyzed
- Revenue and average order value
- Monthly revenue trend
- Category performance
- Top products
- City-wise revenue
- Repeat-customer behavior

## How to run
```bash
pip install -r requirements.txt
python analysis.py
```

Open `dashboard/` to view generated charts.

## Project structure
- `data/retail_sales.csv` - synthetic transaction dataset
- `data/customers.csv` - customer reference data
- `analysis.py` - Python analysis
- `sql/retail_analysis.sql` - SQL queries
- `dashboard/` - generated charts
- `notebooks/retail_analysis.ipynb` - notebook starter

## Interview explanation
"I built a retail customer analytics project using Python, Pandas and SQL. I cleaned transaction data, calculated KPIs such as revenue and average order value, analyzed product, category and city performance, and created visualizations to communicate business insights."

**Dataset note:** Data is synthetic and created for portfolio/learning purposes.
